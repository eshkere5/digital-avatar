# Участие в проекте

1. Создайте ветку от `main`.
2. Установите зависимости: `pip install -r requirements.txt`.
3. Перед коммитом запустите `python -m unittest discover -s tests`.
4. Не добавляйте в коммиты токены, ключи и содержимое `data/state`, `data/outbox`.
5. Не ослабляйте защиту: категории из «Никогда без подтверждения» не должны переводиться в авто, письма и рассылки уходят только после решения руководителя.
6. Опишите в pull request, что изменено и как проверено.

Изменения внешнего вида: правьте переменные в `app/web/app.css` и сверяйтесь с `docs/CUSTOMIZATION.md`.

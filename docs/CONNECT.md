# Подключение: видеозвонки, Telegram, ключи

## Запуск с расширениями
Локально: `python run.py` (адрес `http://127.0.0.1:8000`). На хостинге: `uvicorn app.main:app --host 0.0.0.0 --port $PORT`.
Команда `app.server:app` тоже работает, но без проверки Telegram, привязки чата, ключа администратора и токенов из окружения.

## Сцена аватара для видеозвонка
Кнопка «Режим звонка» в шапке (или вкладка «Встреча» → «Открыть сцену аватара») открывает отдельное окно `/static/stage.html`:
аватар с анимацией речи, субтитры, озвучка ответов, голосовой ввод вопроса и текстовое поле. Фон светлый, тёмный или зелёный (хромакей),
размер кадра 1280×720 или 1920×1080. Клавиши: `S` начать встречу, `M` говорить, `C` субтитры, `B` фон, `F` во весь экран, `H` справка.

Прямого API для «живых аватаров» у МТС Линк, Zoom, Дион и Телемоста нет, поэтому подключение идёт одним из двух способов.

**A. Показ вкладки со звуком (без установок).** В платформе нажмите «Демонстрация экрана», выберите вкладку Chrome со сценой и включите передачу звука.
В веб-версии МТС Линк звук передаётся только в режиме «Вкладка Chrome» ([справка](https://help.mts-link.ru/article/19835)).
У Диона звук включается галочкой в окне выбора ([справка](https://faq.dion.vc/ru/users/functionality_in_the_room)), у Телемоста есть переключатель звука ([справка](https://yandex.ru/support/yandex-360/customers/telemost/web/ru/call/demonstration)).

**B. Виртуальная камера и микрофон.** Установите OBS Studio, добавьте источник «Захват окна» со сценой, нажмите «Запустить виртуальную камеру»
и выберите «OBS Virtual Camera» в настройках видео платформы ([руководство OBS](https://obsproject.com/kb/virtual-camera-guide)).
Виртуальная камера передаёт только картинку: для голоса нужен виртуальный аудиокабель (VB-Cable на Windows, BlackHole на macOS), его выбирают микрофоном в платформе.
МТС Линк прямо пишет, что виртуальная камера у них «не относится к гарантированному функционалу» ([справка](https://help.mts-link.ru/article/29623)), поэтому для неё надёжнее вариант A.

Проверьте выбранный способ на тестовой встрече до питча: автоматических проверок на живых платформах в проекте нет.
Голос аватара генерирует браузер (speechSynthesis), качество зависит от установленных русских голосов.

## Telegram
1. В Telegram откройте @BotFather, команда `/newbot`, скопируйте токен.
2. Задайте токен: во вкладке «Подключения» или переменной окружения `TELEGRAM_BOT_TOKEN` (для публичного стенда лучше так).
3. «Подключения → Telegram → Проверить токен» покажет имя бота.
4. Напишите боту любое сообщение, нажмите «Обновить список», выберите чат и руководителя, нажмите «Привязать». Бот пришлёт подтверждение.
5. Кнопка «Отправить тест» и команда `/plan` в чате проверяют связь. Кнопки «Утвердить» и «Отклонить» под протоколом работают через long polling.

Пока сервис спит (бесплатный тариф Render), бот не получает сообщения.

## Переменные окружения
| Переменная | Назначение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен бота, перекрывает значение из интерфейса |
| `GRAPH_TOKEN` | токен Microsoft Graph для Outlook |
| `OPENAI_API_KEY`, `ANTHROPIC_API_KEY`, `GEMINI_API_KEY`, `DEEPSEEK_API_KEY`, `MISTRAL_API_KEY`, `OPENROUTER_API_KEY` | ключи моделей |
| `AVATAR_LLM_PROVIDER`, `AVATAR_LLM_MODEL` | включить провайдера без интерфейса, например `deepseek` и `deepseek-chat` |
| `AVATAR_ADMIN_KEY` | защита настроек и Telegram на публичном стенде |
| `HOST`, `PORT` | адрес и порт для `python run.py` |

## Публичный стенд
Без пароля любой посетитель может менять настройки. Задайте `AVATAR_ADMIN_KEY`: тогда сохранение настроек и все действия с Telegram требуют ключ,
интерфейс спросит его один раз за сессию. Ключи моделей и токены держите в переменных окружения, а не в интерфейсе.
